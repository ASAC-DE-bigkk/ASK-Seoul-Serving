# 0008 — 후속으로 미룬 것 (deferred)

- 상태: **채택** (2026-08) — 이 목록에 있는 것은 "지금 안 한다"가 결정이다

[reference/](../reference/) 카탈로그와 옛 CLAUDE.md 가 그리던 것 중 **채택하지 않은 전부**를
한 곳에 모은다. 각 항목은 잘못이 아니라 **시기상조**다 — 도입 신호가 실측되면 그때
신규 결정 문서를 쓰고 들여온다.

| 항목 | 왜 지금 아닌가 | 도입 신호 |
|---|---|---|
| Cloudflare Queues + Log Consumer | 원본 하나([0003](0003-single-shared-local-d1.md))로 충분. 호출 이력이 과금 근거가 아니다 | 로그 유실 불허 요구, 과금 도입 |
| R2 원문 저장 | 원문 자체를 안 남긴다(게이트웨이 "값이 아니라 축만" 원칙) | 오류 원문 보관 요구 |
| Durable Objects | 강한 일관성·글로벌 즉시 차단 요구 없음 | 수 초 내 글로벌 차단, 실시간 과금 차단 |
| Analytics Engine | D1 집계로 충분한 규모 | 집계 쿼리 병목, 초 단위 실시간 차트 요구 |
| Cloudflare Access / org OAuth | 로컬 전용([0002](0002-local-only-mentor-gate.md))이라 붙일 곳이 없다 | **공개 배포 시 필수** ([0004](0004-read-open-write-token.md)) |
| 운영자 RBAC (VIEWER/ADMIN…) | 운영자가 사실상 1인 | 운영 인원 증가, 권한 사고 우려 실측 |
| 운영자 감사 로그 | "누가"를 남길 인증이 없다(공유 토큰) | Access/OAuth 도입과 동시 |
| 자동 이상 탐지·자동 차단 | 정상 데이터·오탐 사례 축적 전 | 수동 대응이 병목이 될 때 |
| 알림(정기런 실패 푸시) | 콘솔은 조회 전용. 푸시는 Airflow 콜백(DeadlineAlert) 소관 | 팀 채널 연동 요구 |
| Terraform / IaC | 관리할 원격 리소스가 없다 | 공개 배포로 원격 리소스가 생길 때 |
| TypeScript + 공유 계약 패키지 | 단일 파일 JS 규모. 계약 소비자가 화면 하나 | Worker·소비자 증가로 계약 드리프트 실측 |
| 모노레포 apps/·packages/ 구조 | Worker 2개, 공유 코드 0줄 | 공유 계약 패키지가 실제로 생길 때 |
| `error.code` 공통 오류 봉투 | problem+json 으로 이미 일관 | 외부 SDK 제공 등 코드 기반 분기 요구 |
| API Key 셀프서비스 포털 | 게이트웨이 발급 흐름으로 충분 | 수동 대응이 병목이 될 때 |
| 5-상태 키 모델 | active/revoked 로 충분 ([0006](0006-key-hash-identifier.md)) | 만료·승인 대기 요구 |

## 이 문서의 사용법

- 여기 있는 항목을 구현하자는 제안이 오면 — **도입 신호가 실측되었는지**부터 확인한다.
- 신호가 확인되면: 신규 결정 문서(사유·비용·단순 대안·롤백) → 이 표에서 제거 →
  [index](../index.md) 갱신.
- 신호 없이 들여오는 것은 [CLAUDE.md](../../CLAUDE.md) 4절(불변 경계) 위반이다.
