# 0005 — 파이프라인 SLO 는 D1 스냅샷으로 복사한다

- 상태: **채택** (2026-07) · **일부 폐지 예고** (2026-08 개정 — 아래 §공급자가 바뀌었다)

## ⚠️ 공급자가 바뀌었다 — Trino 경로는 더 이상 정본이 아니다

이 문서를 쓸 때는 `_ops_slo` 를 채울 방법이 Trino 복사뿐이었다. 그 사이 팀 규약
**ASK-Seoul#78** 이 서고 조회 DB 적재가 **실제로 동작하기 시작했다.**

- **#78 D-2**: "기존 `_ops_slo`·`_ops_domain` 은 스키마를 바꾸지 않는다. 화면이 이미 쓰는
  계약이며, **위 4종에서 값을 채운다**" — 즉 `_ops_slo` 의 공급자는
  `_ops_run_event`·`_ops_daily_metric`·`_ops_pipeline_state`·`_ops_pipeline_expectation` 이다.
- **ASAC-DAG#647** 병합 → **#655**(2026-08-03) 검증 완료: 실제 조회 DB 에 **표 4종 생성 ·
  52건 적재**(citydata 35 · weather 6 · traffic 7 · transit 4) · 기대 주기 9행 등록.

따라서 **`scripts/load_slo.py`(Trino REST)는 정규 경로가 아니라 로컬 폴백**이다. 화면이
그것을 "실측으로 바꾸는 방법"의 정본처럼 안내하면 안 된다 — 팀은 이미 D1 에 싣고 있고,
남은 일은 **콘솔이 4종을 읽는 것**(direction.md 축 1)이다.

- 아래 "결정"의 Trino 관련 항목은 **축 1 이 붙을 때까지의 임시 수단**으로 읽는다.
- **선행 필수(#78 D-6)**: 콘솔 마이그레이션이 `DROP TABLE IF EXISTS` 로 시작한다
  ([0007](0007-schema-single-file-reset.md)). 팀 조회 DB 에 표를 만들기 **전에** 증분으로
  바꿔야 한다 — 안 바꾸면 첫 스키마 수정이 팀 데이터를 지운다.
- 이 문서의 전면 개정은 축 1 구현 PR 에서 한다.

## 맥락

파이프라인 품질의 원본은 웨어하우스(Trino, `iceberg_dev.*.gold_*_slo_daily`)에 있다.
그런데 Trino 는 `http://trino:8080` — **Docker 내부 주소라 Cloudflare Worker 가 닿지 못한다.**

## 결정

- SLO 요약을 D1 `_ops_slo` 로 **복사해서 읽는다.** 마트가 날짜 1행이라
  도메인 6개 × 1년 = 2,200행 — 웨어하우스 이동이 아니라 요약 한 줌이다.
- `scripts/load_slo.py` 는 **임시 로더**다. 의존성 없이 Trino REST 를 직접 호출한다.
  정규 경로는 culture DAG 의 export task 여야 하고(팀 D1 쓰기 = 멘토 게이트), 그때까지
  이 스크립트가 **export task 가 무엇을 하면 되는지의 실행 가능한 명세**를 겸한다.
- 합성 폴백(`fixtures/slo_sample.sql`)은 Trino 없는 사람을 위해 남긴다. 모든 행에
  **`is_sample=1`** 이 박히고 화면에 '샘플' 배지가 뜬다 — 실측인 척 조용히 섞이는 게 최악이다.
- 도메인 등록부 `_ops_domain` 은 **SLO 마트가 없는 도메인도 행으로 남긴다.**
  실측(2026-07-28) `1 / 6` — 나머지 5개는 품질을 잴 수단 자체가 없다는 관측이 이 콘솔이
  팀에 던지는 첫 질문이다.
- 초록 위장(`green_disguise_runs` — Airflow success 인데 expected=0)은 SLO 통과로 계산되는
  날이라 실패 목록에 안 잡힌다. 반드시 별도 컬럼으로 싣고 화면에서 붉게 칠한다
  (7/7 실사례).

## 대가

- 스냅샷이라 실시간이 아니다 — 로더를 돌린 시점까지만 맞다.
- 로더·픽스처·스키마(0001 파일) 세 곳이 같은 컬럼 목록을 알아야 한다.

## 재검토 조건

culture DAG 에 export task 가 정규화될 때(멘토 게이트) — 그때 `load_slo.py` 를 폐기하고
이 문서를 개정한다. 나머지 도메인의 SLO 마트는 각 도메인 담당의 몫이다(팀 합의).
