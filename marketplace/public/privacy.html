개인정보 처리방침

ASK: SEOUL(이하 “서비스”)은 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하게 처리할 수 있도록 다음과 같이 개인정보 처리방침을 수립·공개합니다.

시행일 2026년 8월 7일

제1조 (개인정보의 처리 목적)

  • ①
    서비스는 API 키 발급과 그 이용 관리를 위해 최소한의 개인정보를 처리합니다.
  • ②
    처리 목적은 이메일당 1개의 키를 식별하는 것, 발급 남용을 방지하는 것, 어떤 데이터가 실제로 이용되는지 측정하고 장애·남용에 대응하는 것입니다.
  • ③
    처리한 개인정보는 위 목적 외의 용도로 이용하지 않으며, 목적이 변경되는 경우 사전에 동의를 받습니다.

제2조 (수집하는 개인정보의 항목 및 수집 방법)

  • ①
    이용자가 제공하는 정보
    항목수집 시점수집 방법
    이메일 주소API 키 발급Google 로그인(OAuth 2.0)을 통해 Google 로부터 전달받습니다. 서비스가 직접 입력받지 않습니다.
  • ②
    서비스 이용 과정에서 자동으로 생성·수집되는 정보
    항목수집 시점수집 방법
    발급 요청 IP의 해시API 키 발급요청 시 자동 수집하여 즉시 해시로 변환합니다.
    API 요청 기록API 호출호출 시 자동으로 생성됩니다.
    재발급 횟수와 그 날짜키 재발급키 정보에 함께 기록됩니다. 새로 수집하는 정보가 아니라 횟수를 세는 숫자입니다.

    이 항목들은 그 자체로는 특정 개인을 알아볼 수 없으나, 서비스가 보유한 다른 정보와 결합하면 알아볼 수 있습니다. 따라서 개인정보로 보아 관리합니다. 결합의 통로는 다음 둘이며, 그래서 보유 기간을 짧게 두었습니다(제3조).

    • API 요청 기록의 키 해시는 이메일과 1:1 로 대응합니다 — 이용자가 키를 완전 삭제하면 그 대응이 사라져 더는 연결되지 않습니다(제7조).
    • 발급 요청 IP의 해시는 서비스가 보유한 비밀값을 알면 같은 날 안에서는 원문을 되찾을 수 있습니다 — 24시간 뒤 삭제되며, 날이 바뀌면 앞뒤 기록이 서로 이어지지 않습니다.
  • ③
    API 요청 기록에 남는 항목은 호출 경로, 제품(테이블)명, 응답 상태, 응답 행수, 소요 시간, 키 해시, 그리고 필터로 사용한 컬럼의 이름입니다.
  • ④
    이메일 주소는 암호화하지 않은 상태로 저장됩니다.

제3조 (개인정보의 보유 및 이용 기간)

  • ①
    서비스는 법령에 따른 별도의 보유 의무가 없으며, 각 항목을 다음 기간 동안만 보유합니다.
    항목보유 기간근거
    이메일 주소이용자의 삭제 요청 시까지키 식별에 필요한 기간
    발급 요청 IP의 해시24시간시간당 발급 횟수 제한에 필요한 기간
    API 요청 기록30일장애·남용 대응에 필요한 기간
    재발급 횟수와 그 날짜이메일 주소와 같음하루 재발급 횟수 제한에 필요한 기간 — 날이 바뀌면 새로 셉니다
  • ②
    보유 기간이 지난 정보는 자동으로 삭제되며, 이용자의 별도 요청이 필요하지 않습니다.

제4조 (개인정보의 파기 절차 및 방법)

  • ①
    보유 기간이 지나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다.
  • ②
    파기는 저장소에서의 삭제로 이루어지며, 별도의 백업 사본을 보관하지 않습니다.
  • ③
    이용자가 삭제를 요청한 경우 별도의 승인 절차 없이 즉시 반영됩니다(제7조).

제5조 (개인정보의 제3자 제공)

  • ①
    서비스는 이용자의 개인정보를 제3자에게 제공하지 않으며, 판매하지 않습니다.
  • ②
    법령에 근거하여 수사기관이 적법한 절차로 요구하는 경우에만 예외적으로 제공될 수 있습니다.

제6조 (개인정보 처리의 위탁)

  • ①
    서비스는 원활한 운영을 위해 다음과 같이 개인정보 처리 업무를 위탁하고 있습니다.
    수탁자위탁 업무보관 위치
    Cloudflare, Inc.서비스 인프라 운영 및 데이터 저장Cloudflare 글로벌 네트워크
    Google LLC로그인(계정 소유 확인)Google 인프라
  • ②
    수탁자가 변경되는 경우 이 처리방침을 통해 공개합니다.

제7조 (정보주체의 권리·의무 및 행사 방법)

  • ①
    이용자는 언제든지 자신의 개인정보에 대한 열람·정정·삭제·처리정지를 요구할 수 있습니다.
  • ②
    삭제는 이용자가 직접 처리할 수 있습니다. 카탈로그 화면의 ‘내 사용량’ 아래 키 폐기 버튼을 사용하거나, API 를 직접 호출하셔도 됩니다.
    • 폐기 — DELETE /api/v1/keys. 키가 즉시 무효가 되며, 이메일은 남아 같은 주소로 새 키를 받으실 수 있습니다.
    • 완전 삭제 — DELETE /api/v1/keys?purge=true. 키와 이메일·사용량 기록까지 삭제합니다. 이미 폐기한 키로도 호출할 수 있습니다.
  • ③
    삭제 후에도 API 요청 기록(30일 보존)은 남습니다. 다만 그 기록에는 키 해시만 있고 삭제로 해시와 이메일의 대응이 사라지므로 더는 특정 개인과 연결되지 않습니다. 30일이 지나면 자동 삭제됩니다.
  • ④
    권리 행사는 문의 창구를 통해서도 요청하실 수 있습니다.

제8조 (수집하지 않는 정보)

  • ①
    서비스는 다음 정보를 수집하거나 저장하지 않습니다.
    • API 키 원문 — SHA-256 해시와 표시용 접두 8자만 저장하며, 서비스도 원문을 복원할 수 없습니다.
    • 필터에 넣은 값 — 컬럼의 이름만 남기고 값은 버립니다.
    • 발급 요청 IP의 원문 — 날짜와 비밀값을 함께 섞은 해시만 남깁니다. 같은 날 안에서는 같은 값이라 시간당 횟수를 셀 수 있으나, 날이 바뀌면 값이 달라져 앞뒤 기록이 서로 이어지지 않습니다. 다만 비밀값을 아는 서비스는 같은 날 안에서 원문을 되찾을 수 있으므로, 이 기록은 24시간 뒤 삭제합니다(제3조).
    • 인증 없는 요청의 식별자 — 미리보기 등 인증 없는 요청은 키 해시가 비어 있어 개인 단위로 묶을 수 없습니다.

제9조 (쿠키의 사용)

  • ①
    서비스는 로그인 과정에서 쿠키 1개를 사용합니다.
    이름목적속성유효 기간
    ask_oauth_state로그인 요청 위조(CSRF) 방지HttpOnly · SameSite=Lax · Secure(HTTPS) · 경로 /api/v1/auth 한정10분
  • ②
    이 쿠키에는 개인을 식별할 수 있는 정보가 들어 있지 않으며, 서명된 임시 난수만 담깁니다. 로그인이 끝나면 즉시 만료 처리됩니다.
  • ③
    서비스는 광고·분석·트래킹 목적의 쿠키를 사용하지 않으며, 제3자 트래킹 스크립트를 포함하지 않습니다.

제10조 (개인정보의 안전성 확보 조치)

  • ①
    최소 수집 — 목적에 필요하지 않은 항목은 처음부터 받지 않습니다(제8조).
  • ②
    비가역 처리 — API 키는 해시로만, 발급 IP 는 일 단위로 교체되는 비밀값을 섞은 해시로만 저장합니다.
  • ③
    전송 구간 암호화 — 모든 통신은 HTTPS(TLS)로 이루어집니다.
  • ④
    노출 최소화 — 운영 화면에서도 이메일은 마스킹된 형태로만 표시됩니다.
  • ⑤
    자동 파기 — 보유 기간이 지난 정보는 사람의 조작 없이 삭제됩니다.

  • ③
    상시 대기하는 지원 인력이 없어 답변 시점을 약속드리지 못합니다.
