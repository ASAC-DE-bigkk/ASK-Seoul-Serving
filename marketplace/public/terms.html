카탈로그 API 문서 가이드 상태

이용약관

ASK: SEOUL 데이터 API 를 이용하실 때 적용되는 조건입니다. 무엇을 보장하고 무엇을 보장하지 않는지, 어떤 규칙으로 쓰실 수 있는지 적어 두었습니다.

시행일 2026년 8월 7일

제1조 (목적)

  • ①
    이 약관은 ASK: SEOUL(이하 “서비스”)이 제공하는 데이터 API 의 이용 조건과 이용자와 서비스의 권리·의무를 정하는 것을 목적으로 합니다.

제2조 (서비스의 성격)

  • ①
    서비스는 학습 목적으로 운영되는 프로젝트입니다. 별도의 서비스 수준 목표(SLA)를 두지 않으며, 예고 없이 중단·변경·초기화될 수 있습니다.
  • ②
    업무 연속성이 필요한 용도로 의존하지 마시기 바랍니다.
  • ③
    서비스는 무료로 제공되며, 이용 대가를 청구하지 않습니다.

제3조 (이용 계약의 성립과 API 키)

  • ①
    이용자가 Google 로그인을 통해 API 키를 발급받은 시점에 이 약관에 동의한 것으로 봅니다.
  • ②
    API 키는 이메일 주소당 1개가 발급되며, 발급 요청은 IP 당 시간당 5회로 제한됩니다.
  • ③
    API 키는 발급받은 본인만 사용합니다. 타인에게 공유·양도·재배포할 수 없으며, 키가 노출된 경우 이용자가 직접 폐기하고 다시 발급받아야 합니다.
  • ④
    쿼터 우회를 목적으로 복수의 키를 발급받지 않습니다.

제4조 (이용 한도)

  • ①
    서비스는 두 층의 한도를 둡니다. 일일 쿼터는 한 이용자가 하루에 얼마나 쓰는지를, 분당 한도는 지금 이 순간 서비스에 얼마나 부하를 주는지를 제한합니다.
    구분한도초과 시
    분당 한도60건429 와 Retry-After 헤더로 재시도 시각을 알려드립니다
    일일 쿼터키당 1,000회 (KST 자정 리셋)429 를 반환합니다
  • ②
    분당 한도는 인증 요청은 키 단위로, 인증 없는 미리보기는 IP 단위로 셉니다.
  • ③
    다음 요청은 일일 쿼터를 소모하지 않습니다.
    • 분당 한도로 막힌 요청
    • 유효하지 않은 요청(400 · 404 · 409)
    • 인증 없는 미리보기(/api/v1/preview) · 제품 검색(/api/v1/search)
    • 메타 조회(/api/v1/products · /api/v1/glossary)
    • 아직 준비되지 않은 제품을 조회한 경우 — 빈 결과를 돌려드리며 차감하지 않습니다
    • 서비스 잘못으로 실패한 요청(500) — 이미 차감된 몫을 되돌려 드립니다. 되돌리기까지 성공한 경우에만 응답에 quota_charged: false 가 실리므로, 그 값이 없으면 차감이 남아 있을 수 있습니다 — 그때는 문의로 알려 주시면 확인해 드립니다
  • ④
    페이지도 한 건씩 계상됩니다. 큰 제품을 cursor 로 나눠 받으면 페이지 수만큼 쿼터를 사용합니다 — 한 번에 받는 행 수(limit, 최대 5,000)를 키우면 호출 수를 줄일 수 있습니다.

제5조 (데이터의 이용과 재배포)

  • ①
    서비스가 제공하는 데이터는 공공 원천을 수집·가공한 2차 산출물입니다.
  • ②
    각 원천의 이용허락 범위(공공누리 유형, 상업적 이용 가능 여부, 출처 표시 의무 등)는 제공기관의 고지를 따르며, 서비스가 이를 대신 부여하거나 완화할 수 없습니다. 재배포·상업적 이용 전에 데이터 출처와 이용조건에서 원천별 조건을 직접 확인하시기 바랍니다.
  • ③
    서비스의 응답을 인용하실 때는 원천 제공기관과 서비스를 함께 표시해 주시기 바랍니다. 가공 과정이 있으므로 원천만 표시하면 원천의 공식 수치로 오인될 수 있습니다.

제6조 (이용자의 의무)

  • ①
    이용자는 다음 행위를 하지 않습니다.
    • API 키를 공유·양도·재배포하는 행위
    • 쿼터 우회를 목적으로 복수의 키를 발급받는 행위
    • 과도한 동시 요청, 취약점 탐색 등 서비스의 정상 운영을 방해하는 행위
    • 원천 데이터의 이용조건을 위반하는 방식으로 재배포하는 행위
    • 타인의 권리를 침해하거나 법령을 위반하는 목적으로 이용하는 행위

제7조 (보증의 부인)

  • ①
    서비스는 제공하는 데이터의 정확성·완전성·적시성을 보증하지 않습니다.
  • ②
    안전·의료·법률·재산에 관한 의사결정의 단독 근거로 사용하지 마시기 바랍니다. 특히 기상 위험 신호는 기상청의 공식 특보가 아니며, 실시간 제품은 원천 관측과 시차가 있습니다 — 자세한 내용은 특히 주의할 제품을 참고하시기 바랍니다.
  • ③
    서비스는 중단·지연·데이터 손실에 대해 보증하지 않습니다.

제8조 (책임의 제한)

  • ①
    서비스는 무료로 제공되는 학습 프로젝트로서, 이용자가 서비스를 이용하거나 이용할 수 없음으로 인해 발생한 손해에 대하여 고의 또는 중대한 과실이 없는 한 책임을 지지 않습니다.
  • ②
    이용자가 제5조·제6조를 위반하여 발생한 문제(원천 이용조건 위반 등)에 대한 책임은 이용자에게 있습니다.

제9조 (이용 제한)

  • ①
    제6조를 위반하거나 서비스 운영에 지장을 주는 경우, 서비스는 사전 통지 없이 API 키를 폐기할 수 있습니다.
  • ②
    폐기된 키로 조회를 요청하면 403 을 반환합니다.
  • ③
    이용자는 언제든지 스스로 키를 폐기할 수 있습니다 — 개인정보 처리방침 제7조의 방법을 참고하시기 바랍니다.

제10조 (개인정보의 처리)

  • ①
    서비스가 수집·이용하는 개인정보와 그 처리 방법은 개인정보 처리방침에 따릅니다.

제11조 (문의)

  • ①
    키 폐기와 정보 삭제는 이용자가 직접 처리할 수 있으며, 문의를 기다리실 필요가 없습니다.
  • ②
    그 밖의 문의·오류 신고는 문의 페이지의 창구를 이용해 주시기 바랍니다.
  • ③
    상시 대기하는 지원 인력이 없어 답변 시점을 약속드리지 못합니다.

제12조 (약관의 변경)

  • ①
    이 약관은 시행일부터 적용됩니다.
  • ②
    서비스의 변경에 따라 약관이 개정되는 경우 변경 사항의 시행 전에 이 페이지를 통해 공개합니다.
  • ③
    변경된 약관의 시행일 이후에도 서비스를 계속 이용하는 경우 변경에 동의한 것으로 봅니다.
