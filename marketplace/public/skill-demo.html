서울, 언제 날씨를 조심해야 할까?

서울 행정동 이름으로 물어보면, 더위·비·강풍에 주의할 시간대를 알려드려요.

Codex 또는 Claude Code에 이 기능을 설치한 뒤, 내 AI에서 질문해 보세요.

1. AI에 설치하기 2. 내 API 키 연결 3. 연결 상태 확인
1 Get started

AI에서 사용 준비하기

Codex 또는 Claude Code에 한 번 설치하면, 동네 이름으로 날씨 위험 시간을 물어볼 수 있어요.

Codex

npx skills add https://github.com/ASAC-DE-bigkk/ASK-Seoul-Serving/archive/7203c869380f2907175919733b3282742767cbc6.tar.gz --global --agent codex --copy --yes

Claude Code

npx skills add https://github.com/ASAC-DE-bigkk/ASK-Seoul-Serving/archive/7203c869380f2907175919733b3282742767cbc6.tar.gz --global --agent claude-code --copy --yes
설치 정보 보기

설치 명령은 검증된 버전의 skill을 내려받습니다. 명령을 복사해 사용할 AI의 터미널에서 실행하세요.

2 Connect

내 API 키 연결하기

ASK 서울에서 발급한 내 API 키를 입력하세요. 아직 키가 없다면 새 탭에서 발급할 수 있어요.

입력한 키는 이 화면의 연결 상태를 확인할 때만 사용되며 저장되지 않습니다.
AI 환경에도 키 연결하기

페이지에 입력한 키는 Codex·Claude로 전달되지 않습니다. 설치한 AI가 데이터를 읽을 수 있도록, 같은 키를 AI를 실행할 프로젝트의 .env에 직접 저장하세요.

KSKILL_LOCAL_DIRECT=1
ASK_SEOUL_SKILL_API_BASE_URL=https://ask-seoul.kr
MARKETPLACE_API_KEY=<PASTE_LOCALLY>
3 Check

연결 상태 확인하기

내 API 키로 날씨 데이터가 정상적으로 준비되어 있는지 확인합니다. 확인에 성공하면 AI에 넣을 예시 질문을 보여드려요.

API 키를 입력한 뒤 연결 상태를 확인해 주세요.
데이터·검증 정보 보기

연결 확인에 사용한 기술 정보입니다. 시연과 문제 확인이 필요할 때만 펼쳐 보세요.

  1. bundleregistration_ready=true
  2. productregistration_ready=true
  3. datarow_count > 0 및 샘플 한 행
publication_id
row_count
request_id
