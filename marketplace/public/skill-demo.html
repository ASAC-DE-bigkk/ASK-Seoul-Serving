1. 설치 2. 연결 3. 검증
1 Install

AI 환경에 standalone skill 설치

설치 URL은 Serving이 검증한 artifact commit에 고정됩니다. 공개 npm K-Skill을 다시 호출하지 않습니다.

Codex

npx skills add https://github.com/ASAC-DE-bigkk/ASK-Seoul-Serving/archive/909354e4a4ec5e95f5bde3db5aa6f20d5b2ad8b0.tar.gz --global --agent codex --copy --yes

Claude Code

npx skills add https://github.com/ASAC-DE-bigkk/ASK-Seoul-Serving/archive/909354e4a4ec5e95f5bde3db5aa6f20d5b2ad8b0.tar.gz --global --agent claude-code --copy --yes
2 Authenticate

Marketplace API Key 연결

아직 키가 없다면 새 탭에서 발급하세요. 입력값은 이 탭의 JavaScript 메모리에서만 사용하며 저장하거나 복사 명령에 넣지 않습니다.

요청 미리보기: Authorization: Bearer ••••••••
AI 실행 환경은 별도로 연결합니다. 페이지에 입력한 키는 Codex·Claude로 전달되지 않습니다. 아래 값은 AI를 실행할 프로젝트의 .env에 직접 저장하세요. 
KSKILL_LOCAL_DIRECT=1
ASK_SEOUL_SKILL_API_BASE_URL=https://ask-seoul.kr
MARKETPLACE_API_KEY=<PASTE_LOCALLY>
3 Verify

운영 publication readiness 검증

아래 세 요청이 모두 통과할 때만 publication 증거와 자연어 질문 예시를 표시합니다.

  1. bundleregistration_ready=true
  2. productregistration_ready=true
  3. datarow_count > 0 및 샘플 한 행
API Key를 입력해 주세요.
publication_id
row_count
request_id
